# Infrastructure as Code Reference

## Terraform — Module structure

```
my-module/
├── main.tf          # resources
├── variables.tf     # input variables with descriptions + validation
├── outputs.tf       # exported values
├── versions.tf      # required_providers + terraform version constraint
└── README.md        # auto-generated by terraform-docs
```

### versions.tf (always pin provider versions)
```hcl
terraform {
  required_version = ">= 1.7.0, < 2.0.0"

  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.40"
    }
  }

  backend "s3" {
    bucket         = "my-company-tfstate"
    key            = "services/my-service/production/terraform.tfstate"
    region         = "us-east-1"
    dynamodb_table = "terraform-locks"
    encrypt        = true
  }
}
```

### variables.tf — include validation
```hcl
variable "environment" {
  description = "Deployment environment (dev, staging, production)"
  type        = string
  validation {
    condition     = contains(["dev", "staging", "production"], var.environment)
    error_message = "environment must be dev, staging, or production"
  }
}

variable "instance_type" {
  description = "EC2 instance type for the service"
  type        = string
  default     = "t3.medium"
}
```

### outputs.tf
```hcl
output "service_endpoint" {
  description = "The DNS endpoint for the service load balancer"
  value       = aws_lb.main.dns_name
}

output "service_arn" {
  description = "ARN of the ECS service"
  value       = aws_ecs_service.main.id
  sensitive   = false
}
```

## Terraform — Common patterns

### Data sources (reference existing resources)
```hcl
data "aws_vpc" "main" {
  tags = { Name = "main-vpc" }
}

data "aws_subnets" "private" {
  filter {
    name   = "vpc-id"
    values = [data.aws_vpc.main.id]
  }
  tags = { Tier = "private" }
}
```

### Lifecycle rules
```hcl
resource "aws_db_instance" "main" {
  # ...
  lifecycle {
    prevent_destroy       = true   # require explicit removal
    ignore_changes        = [password]  # managed externally
    create_before_destroy = true   # zero-downtime replacement
  }
}
```

### For_each over maps (prefer over count)
```hcl
variable "services" {
  default = {
    api     = { port = 8080, cpu = 256 }
    worker  = { port = 0,    cpu = 512 }
  }
}

resource "aws_ecs_service" "services" {
  for_each = var.services
  name     = each.key
  # ...
}
```

## Ansible — Playbook structure

```yaml
---
- name: Configure web servers
  hosts: web_servers
  become: true
  gather_facts: true

  vars:
    app_version: "1.2.3"
    app_user: appuser

  pre_tasks:
    - name: Update apt cache
      ansible.builtin.apt:
        update_cache: true
        cache_valid_time: 3600

  roles:
    - common
    - nginx
    - app

  handlers:
    - name: Restart nginx
      ansible.builtin.service:
        name: nginx
        state: restarted
```

### Ansible — Vault for secrets
```bash
# Encrypt a file
ansible-vault encrypt vars/secrets.yml

# Use in playbook
vars_files:
  - vars/secrets.yml   # ansible-vault will decrypt at runtime

# Run with vault password
ansible-playbook site.yml --vault-password-file ~/.vault_pass
```

## Helm — Chart structure

```
my-chart/
├── Chart.yaml
├── values.yaml              # default values
├── values-staging.yaml      # env overrides
├── values-production.yaml
└── templates/
    ├── deployment.yaml
    ├── service.yaml
    ├── ingress.yaml
    ├── hpa.yaml
    ├── pdb.yaml
    ├── serviceaccount.yaml
    ├── configmap.yaml
    └── _helpers.tpl         # named templates
```

### Helm — values.yaml pattern
```yaml
replicaCount: 3

image:
  repository: myregistry/my-service
  tag: ""                  # overridden at deploy time
  pullPolicy: IfNotPresent

resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 512Mi

autoscaling:
  enabled: true
  minReplicas: 3
  maxReplicas: 20
  targetCPUUtilizationPercentage: 70

ingress:
  enabled: true
  className: nginx
  host: my-service.example.com
  tls: true
```

### Helm — deploy commands
```bash
# Lint before deploy
helm lint ./charts/my-service

# Dry-run (template rendering + K8s server-side validation)
helm upgrade --install my-service ./charts/my-service \
  --namespace production \
  --values ./charts/my-service/values-production.yaml \
  --set image.tag=v1.2.3 \
  --dry-run --debug

# Deploy
helm upgrade --install my-service ./charts/my-service \
  --namespace production \
  --values ./charts/my-service/values-production.yaml \
  --set image.tag=v1.2.3 \
  --atomic --timeout=5m    # --atomic rolls back on failure

# Rollback
helm rollback my-service 1 --namespace production
```

## IaC security scanning

```bash
# Terraform
tfsec .                        # static analysis
checkov -d .                   # compliance checks (CIS benchmarks)
terrascan scan -t terraform    # policy-as-code

# Helm
helm lint
kubeconform ./charts/          # schema validation
kube-score score manifest.yaml # security/best practices scoring
polaris audit --format pretty  # Fairwinds Polaris
```
